# Shamal Ninghot Portfolio

Static portfolio site for GitHub Pages.

## Publish with GitHub Pages

1. Upload the repository contents to GitHub, keeping `index.html`, `images/`, and `.github/workflows/pages.yml` at the repository root.
2. In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
3. Push to the `main` or `master` branch, or run **Deploy portfolio to GitHub Pages** from the Actions tab. The workflow publishes the site and reports its URL when deployment finishes.

The portrait is loaded from `images/profile1.jpeg`. The page uses online CDNs for Tailwind CSS, GSAP, and Google Fonts, so those enhancements and fonts require an internet connection.
